About Luanti

Luanti is an open-source voxel game engine. Programmed in C++, and highly extendable via the Lua API, it runs efficiently on low-end hardware as well as top-tier machines.

This UI has been completely modernized using high-performance CSS and HTMLView technologies, resulting in a responsive, low-latency client experience.
